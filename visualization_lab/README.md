# ML算法可视化实验室

一个交互式的机器学习算法可视化 Web 应用（TensorFlow Playground 风格），将本项目 `src/traditional_ml` 中的 24 个经典算法变成"左边调参数、右边看效果"的直观实验台。

## 功能特性

- **分类**：实时绘制 10 种分类器的决策边界（KNN、决策树、随机森林、SVM、AdaBoost、逻辑回归、Softmax回归、朴素贝叶斯、感知机、MLP神经网络）
- **MLP训练动画**：神经网络逐 epoch 决策边界演化动画 + 损失/准确率曲线实时绘制
- **聚类**：6 种聚类算法，K-Means 支持逐迭代动画回放，直观展示质心移动轨迹
- **回归**：4 种回归算法的拟合曲线实时对比
- **降维**：PCA / LDA / SVD / t-SNE 的二维投影散点
- **决策树结构**：决策树与随机森林训练后自动渲染树形 SVG
- **训练/测试划分**：可调测试集比例，空心点标记测试样本，分别报告训练/测试准确率
- **数据集缩略图**：点击缩略图即切换数据集（双月牙、同心圆、异或象限、双螺旋、高斯团块、高维高斯）
- **动态参数**：所有算法参数以滑块呈现，改动即自动重跑（请求合并防抖）

## 快速开始

```bash
# 安装依赖
pip install numpy fastapi uvicorn

# 启动（在本目录下）
python main.py
```

打开浏览器访问 http://localhost:8000 即可使用。

## 使用指南

1. 顶部选择任务类型（分类 / 聚类 / 回归 / 降维）
2. 左侧选择数据集，调整样本数与噪声
3. 点击算法卡片，拖动参数滑块，观察右侧画布实时变化
4. 聚类任务下 K-Means 会自动播放迭代动画，可用 ⏮ ⏭ 逐帧查看
5. 树模型训练后页面下方展示树结构，叶节点按预测类别着色

## 架构

```
visualization_lab/
├── main.py                  # FastAPI 入口（3个API + 静态文件挂载）
├── services/
│   ├── datasets.py          # 8种玩具数据集生成器
│   └── algorithms.py        # 算法注册表 + 统一运行器（决策边界网格/动画帧/树序列化）
└── static/
    ├── index.html           # 单页应用骨架
    ├── css/style.css        # 深色主题样式
    └── js/app.js            # 交互逻辑（Canvas绘制/SVG树/动画播放器）
```

### API

| 接口 | 说明 |
|------|------|
| `GET /api/algorithms` | 返回全部算法目录与参数 schema |
| `POST /api/dataset` | 生成指定类型的数据集 |
| `POST /api/run` | 训练算法，返回决策边界网格 / 聚类标签与动画帧 / 拟合曲线 / 降维投影 |

后端所有计算均调用 `src/traditional_ml` 的纯 NumPy 实现，无 sklearn 依赖。
